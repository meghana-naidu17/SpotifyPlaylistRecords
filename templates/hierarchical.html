How It Works

Linkage → Dendrogram → K → Silhouette (Evaluation)

1. Preprocessed Data

10 pre-scaled continuous audio features from preprocessed_dataset.csv. No re-scaling applied.

2. Linkage Matrix

The selected linkage method ({{ results.method|title }}) builds its own hierarchical merge tree from the data — independently from other methods.

3. Dendrogram Cutoff → K

The largest gap between consecutive merge distances is found. This is the natural "elbow" of the {{ results.method|title }} dendrogram. Cutoff = {{ results.cutoff_dist }} → K = {{ results.selected_k }}.

4. Silhouette = Evaluation

Silhouette score of {{ results.final_silhouette }} measures cluster quality for K = {{ results.selected_k }}. It evaluates the result — it did not choose K.
