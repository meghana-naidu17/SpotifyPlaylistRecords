Method

How this module works

1. Preprocessed Data

The module loads the existing preprocessed CSV instead of the raw Spotify dataset.

2. Feature Preparation

Target columns are excluded, invalid values are handled, and constant columns are removed.

3. Agglomeration

Each track starts as its own group and the closest groups are merged according to the selected linkage.

4. Visualization

A dendrogram explains the hierarchy and PCA provides a two-dimensional view of the resulting clusters.
