The Three-Way Split Discipline & Data Snooping Prevention
In standard 2-way splits (Train/Test), tuning hyperparameters on the test set causes Data Snooping Bias (optimistic error illusion). A disciplined 3-way split holds the Test set in a sealed vault, tuning strictly on Validation to ensure unbiased generalization.

Grid vs Random (Bergstra-Bengio) vs Bayesian Optimization
Grid Search tests a rigid lattice, redundantly re-testing unimportant hyperparameter values. Random Search explores distinct coordinates along every dimension, finding superior configurations in fewer iterations. Bayesian Optimization uses Gaussian Process surrogates and acquisition functions (Expected Improvement) to intelligently guide the search.
