In standard 2-way splits (Train/Test), tuning hyperparameters on the test set causes Data Snooping Bias (optimistic error illusion). A disciplined 3-way split holds the Test set in a sealed vault, tuning strictly on Validation to ensure unbiased generalization.

Hyperparameter Optimization: Grid vs Random Search (Bergstra-Bengio)
Grid Search tests a rigid lattice, redundantly re-testing unimportant hyperparameter values. Random Search explores distinct coordinates along every dimension, finding superior configurations in fewer iterations. Mean cross-validation F1 scores guide hyperparameter selection, while the final selected model is evaluated on the vaulted held-out test set for unbiased generalization.
