Calculations

How the Model Calculates the Prediction

Logistic Regression Equation
Logistic Regression calculates a weighted combination of the input features and converts it into a probability using the sigmoid function. {% if results.penalty == 'l1' %} With L1 regularization, weak or redundant feature weights are pushed to exactly zero. {% elif results.penalty == 'l2' %} With L2 regularization, all feature weights are shrunk smoothly toward zero without eliminating any. {% else %} With no regularization, weights are fit purely to minimize training error, with no penalty term. {% endif %}
Linear score: z = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ
Probability: P = 1 / (1 + e⁻ᶻ)
If the predicted probability is at least 0.5, the track is classified as Explicit; otherwise it is classified as Not Explicit.
