MSE Cost Function & Gradient Descent ({{ results.penalty_label }})

The Cost Function and Optimization
To fit a regression line, we define an objective measure of error and regularize parameter magnitudes to prevent overfitting.
{% if selected_penalty == 'l2' %} Mean Squared Error (MSE) + L2 Ridge Regularization Cost Equation: {% elif selected_penalty == 'l1' %} Mean Squared Error (MSE) + L1 Lasso Regularization Cost Equation: {% else %} Mean Squared Error (MSE) Cost Equation: {% endif %}
{% if selected_penalty == 'l2' %} J(θ) = 1/m * Σ (h_θ(x^(i)) - y^(i))² + λ * Σ θ_j² {% elif selected_penalty == 'l1' %} J(θ) = 1/m * Σ (h_θ(x^(i)) - y^(i))² + λ * Σ |θ_j| {% else %} J(θ) = 1/m * Σ (h_θ(x^(i)) - y^(i))² {% endif %}
Gradient Descent Update Rule: By taking steps in the opposite direction of the gradient of $J(\theta)$, the parameters move toward the optimal regularized solution:
{% if selected_penalty == 'l2' %} θ_j := θ_j - α * [(2/m) * Σ (h_θ(x^(i)) - y^(i)) * x_j^(i) + 2λ * θ_j] {% elif selected_penalty == 'l1' %} θ_j := θ_j - α * [(2/m) * Σ (h_θ(x^(i)) - y^(i)) * x_j^(i) + λ * sign(θ_j)] {% else %} θ_j := θ_j - α * (2/m) * Σ (h_θ(x^(i)) - y^(i)) * x_j^(i) {% endif %}
As we update the parameters iteratively, the cost $J(\theta)$ descends toward the global minimum, and the line converges to the regularized best fit.
