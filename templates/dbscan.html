Theory

How DBSCAN Categorizes Tracks

1. Core Points

A track is a Core point if its ε-neighborhood contains at least Min Samples ({{ results.min_samples }}) tracks. These form the dense anchors of clusters.

2. Border Points

A track is a Border point if it falls within the ε-neighborhood of a Core point, but does not have enough neighbors itself to be a Core point.

3. Noise Points

Tracks that are not reachable from any Core point are marked with label -1 (Noise). These represent unusual tracks or audio outliers.

4. Arbitrary Shapes

Unlike K-Means which enforces spherical clusters, DBSCAN connects overlapping dense neighborhoods, discovering natural musical groupings of any shape.
